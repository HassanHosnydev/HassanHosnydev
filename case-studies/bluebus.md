# BlueBus

Web, operations, and mobile software for bus transportation.

## My contribution

I developed and maintained the public website and administrative platforms for trips, tickets, users, and permissions. I also built operations interfaces covering vehicles, drivers, work orders, trip assignments, customers and suppliers, route pricing, maintenance, invoices, and reporting.

The interfaces support Arabic and English. I implemented role-based access control across administrative and operational workflows.

On mobile, I developed and deployed the React Native application for Android and iOS, including releases through Google Play and the App Store.

## Technical work

- React and Next.js for web interfaces, depending on the application.
- React Native for the mobile app.
- Ant Design and Tailwind CSS for interface development.
- TanStack Query and Axios for server data and API integration.
- React Router and i18next for navigation and Arabic/English support.
- Role-based access control across administrative workflows.
